# SILA Union Development Toolkit — описание на русском

Это независимая портфельная реализация подхода к локальной разработке и тестированию автоматизации репозитория корпоративной архитектуры.

Проект построен по принципу **mock-first**: вся бизнес-логика работает через интерфейс `SilaRepositoryClient`, а unit tests и демонстрационный запуск используют только `InMemorySilaRepositoryStub`. Реальный экземпляр SILA Union, учётные данные, VPN и корпоративная сеть не требуются.

Основные демонстрационные сценарии:

- идемпотентный импорт синтетического глоссария;
- формирование Markdown-снимка архитектурного репозитория;
- тестируемая граница между автоматизацией и будущим vendor adapter;
- GitHub Actions с запуском unit tests на каждом PR и push в `main`;
- дополнительная проверка публичной безопасности перед сборкой.

Основная документация проекта ведётся на английском в [README.md](README.md).
